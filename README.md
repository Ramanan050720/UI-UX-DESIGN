# 🛍️ E-Commerce App UI/UX Design

This repository contains the **UI/UX design** for a modern E-Commerce mobile application.  
The design focuses on a clean, minimal, and user-friendly shopping experience — from login to browsing products on the home page.

---

## 🎨 Overview

- **App Name:** E-Commerce App  
- **Design Tool:** Figma  
- **Platform:** Mobile (Android/iOS)  
- **Pages Included:**
  - Login Page  
  - Home Page (Product Feed, Categories, Offers)

---

## 🧭 Screens

### 🔐 Login Page
- Simple and elegant login screen  
- Includes email/password fields and social login options  
- Subtle gradients and clean typography for clarity

### 🏠 Home Page
- Clean product layout with images, prices, and ratings
